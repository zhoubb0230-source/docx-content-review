# 错词表的负向语料：以下句子**全部合法**，任何一条命中错词表都是误报。
#
# `typo_scan.py lint` 会拿每条错词表左串来撞这些句子，命中即报错。
# 这与 never-flag 的反例、`validate_docx.py` 的负向对照是同一件事：
# **只验"能查出错"不算验，还要验"不会把对的判成错"。**
#
# 为什么必须有这份语料：错词表的立身之本是「扩表不抬高误报率」。
# 一旦某条左串是常见词组的碎片（「按全」← 按全流程，「备按」← 设备按标准，
# 「以经」← 以经验，「换存」← 置换存储），这个前提就不成立了，
# 该条目要么改写成不会被拆开的长形式，要么删掉。
#
# 发现新的误报时，把那句话原样加到这里，再修词表。语料只增不减。
