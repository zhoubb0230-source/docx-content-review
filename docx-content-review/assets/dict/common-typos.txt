# 常见错词表：<错误写法><TAB><正确写法><TAB><说明>
#
# 本表是错别字召回率的**唯一杠杆**，也是可枚举、可收敛的资产——与 never-flag 同性质。
# 扩表永远可做；**放宽闸门②的 A1 阈值永远不可做**（长度差 ≤2 且差异字符 ≤3）。
#
# 三条登记规则：
#   1. **只登记确定的「错→对」映射。** 正确写法一律进 typo-whitelist.txt，不进本表。
#   2. **左列必须是 ≥2 字的串。** 按单字登记会把「度」「作」「帐」这类高频字
#      全部拉成候选，噪音淹没一切。同一个字的不同误用要分别写成含上下文的词。
#   3. **异体/变体不算错。**「其它」「须要」「制订」「泄漏」这类两可写法不登记，
#      它们属于规范偏好（never-flag N6），不是错字。
#
# 候选必须经 LLM 裁定（prompts/pass1-typo.md），脚本候选不得直接生成修订（spec §9.7）。
